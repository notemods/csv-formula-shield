# Check a CSV before you share it

CSV Formula Shield makes a separate escaped copy.

## Sample files

- People.csv has formula text, a negative number, a quoted comma, and a line break.
- Prefixes.csv has control characters and full-width prefixes.
- Collision.csv has an existing escaped copy. The next copy needs a numbered name.
- Broken.csv has a row-width error for the combined report.

## Review steps

1. Choose a CSV from the command palette.
2. Inspect row and column numbers in the preview.
3. Choose the negative number rule.
4. Approve the new copy, or cancel.

The sample cells contain text only. This note does not evaluate formulas.
